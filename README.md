# zezo-pizzaria
Site responsivo desenvolvido para uma pizzaria fictícia, utilizando HTML, CSS e JavaScript.
Este projeto foi desenvolvido com auxílio de ferramentas de Inteligência Artificial, utilizadas como apoio durante o processo de desenvolvimento, principalmente para tirar dúvidas, sugerir soluções e auxiliar na revisão do código.

O projeto também faz parte do meu processo de aprendizado em desenvolvimento web.
